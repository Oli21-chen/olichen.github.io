# GitHub Pages CV site

Upload the contents of this folder to a public GitHub repo named:

`YOURUSERNAME.github.io`

Then enable Pages:

**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/ (root)` → Save**

Your CV will be at:

`https://YOURUSERNAME.github.io`

## Files to upload

| File | Purpose |
|------|---------|
| `index.html` | Landing page |
| `cv.pdf` | Your CV (`CV-Oliver D. Chen.pdf`) |

## Upload via GitHub website

1. Create repo `YOURUSERNAME.github.io` (Public).
2. Click **Add file → Upload files**.
3. Drag `index.html` and `cv.pdf` into the page.
4. Commit.
5. Turn on Pages as above.
6. Wait 1–2 minutes and open the `.io` URL.
